# Support

## Getting help

Use GitHub Issues for bugs, feature requests, and questions.
Provide:
- minimal reproduction repo
- generated `routes.gen.ts` output
- `vite`, `react`, `react-router-dom` / `@tanstack/react-router` versions
- OS and Node version

## Issue types

- Bug report: incorrect route generation, runtime breakage, typing regressions
- Feature request: new file conventions, adapter behavior, DX improvements
- Security: report privately via GitHub Security Advisory (see `SECURITY.md`)

## Best-effort scope

- Latest release and latest `main`
- React Router adapter is production target
- TanStack adapter is currently marked experimental
